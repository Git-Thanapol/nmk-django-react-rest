📊 Dashboard — หน้าหลักของระบบ

หน้า Dashboard เปิดมาแล้วจะเห็นภาพรวมทั้งหมดของธุรกิจ อัปเดตแบบ Real-time

มีอะไรให้ดูบ้าง?
  • KPI Summary — ยอดซื้อรวม, ยอดขายรวม, กำไร, ภาษี ของช่วงเวลาที่เลือก
  • Sales Trend — กราฟแนวโน้มยอดขายย้อนหลัง N วัน
  • Top Products — สินค้าขายดีอันดับต้นๆ
  • Purchase vs Sales — เปรียบเทียบซื้อ vs ขาย รายเดือน
  • Stock Alerts — สินค้าใกล้หมด stock (ต่ำกว่า threshold)
💡 เทคนิค

กรองข้อมูลตามบริษัทได้ ถ้ามีหลายบริษัทในระบบ ใช้ dropdown เลือกบริษัทที่ต้องการดู หรือเลือก "ทุกบริษัท" เพื่อดูภาพรวม

🛒 ใบสั่งซื้อ (Purchase Order)

ใช้บันทึกการซื้อสินค้าจากซัพพลายเออร์ เมื่อบันทึกแล้ว stock สินค้าจะเพิ่มขึ้น

วิธีสร้างใบสั่งซื้อใหม่
1คลิก รายการซื้อเข้า ในเมนูด้านซ้าย
2กรอก เลขที่เอกสาร (PO Number) — ต้องไม่ซ้ำกันในแต่ละบริษัท
3เลือก ผู้จำหน่าย (Vendor) และ บริษัท
4เลือก วันที่ และ ประเภทการซื้อ
5เพิ่มรายการสินค้า: เลือกสินค้า, ใส่จำนวน, ราคา/หน่วย
6กดปุ่ม บันทึก
สถานะใบสั่งซื้อ
Draft — บันทึกไว้ก่อน ยังไม่จ่ายเงิน
Paid — จ่ายเงินแล้ว stock เข้าระบบ
Cancelled — ยกเลิกแล้ว
⚠️ ข้อควรระวัง

เมื่อเปลี่ยนสถานะเป็น Paid แล้ว จะแก้ไขรายการสินค้าไม่ได้ ถ้าต้องการแก้ต้อง Cancelled แล้วสร้างใหม่

ฟีเจอร์เพิ่มเติม
  • แนบไฟล์ — แนบใบเสร็จ/ใบกำกับจากผู้จำหน่ายได้ (ใบ Paid สามารถแนบไฟล์ได้)
  • ข้อมูลภาษี — ใส่วันที่ออกภาษีและเลขที่ลำดับ สำหรับรายงานภาษีซื้อ
  • ส่วนลด — ใส่ส่วนลดได้ทั้งแบบจำนวนเงิน
  • VAT — เลือกว่าราคาในใบ include VAT อยู่แล้วหรือยัง และ % ภาษี
💡 เกี่ยวกับ Stock

Stock จะถูกนับก็ต่อเมื่อใบสั่งซื้อ Paid เท่านั้น ถ้า Draft อยู่ยังไม่เข้า stock

🧾 ใบกำกับภาษี / ใบขาย (Invoice)

ใช้บันทึกการขายสินค้า ระบบจะตัด stock ออกอัตโนมัติและคำนวณกำไรให้

วิธีสร้างใบขายใหม่
1คลิก ใบกำกับ/ใบขาย ในเมนูด้านซ้าย
2กรอกเลขที่ใบกำกับ, วันที่, เลือกบริษัท
3ใส่ข้อมูลลูกค้า: ชื่อ, เบอร์โทร, ที่อยู่จัดส่ง (ถ้ามี)
4ถ้าขายผ่าน Platform ให้ใส่ Platform Name, Order ID, Tracking Number
5เพิ่มสินค้า: เลือก Product → ระบบดึง Batch (lot) ให้อัตโนมัติแบบ FIFO
6กดบันทึก — stock ลดลงทันที (ถ้าสถานะ Billed)
สถานะใบขาย
Draft — ร่าง ยังไม่ตัด stock
Billed — ขายแล้ว stock ออก
Cancelled — ยกเลิก stock คืนกลับ
Export ออกมาได้ทั้ง PDF และ Excel
  • ปุ่ม 🖨️ Print PDF — ออก PDF ใบกำกับภาษี และเปลี่ยนสถานะเป็น Billed อัตโนมัติ
  • ปุ่ม 📊 Export Excel — ส่งออกรายการสินค้าในใบเป็น Excel
ℹ️ FIFO (First-In, First-Out)

ระบบจะเลือก Batch สินค้าที่ซื้อมาก่อนขายก่อนให้อัตโนมัติ เพื่อให้ต้นทุนถูกต้อง ถ้าต้องการเลือก Batch เองก็สามารถทำได้ผ่าน dropdown

Sync จาก Google Sheet

ถ้ามีรายการขอใบกำกับจาก Google Form สามารถ Sync เข้าระบบได้ผ่านปุ่ม Sync Google Sheet หน้า Invoice list

📦 สินค้า (Products)

จัดการ Master Catalog ของสินค้าทั้งหมด แต่ละรายการมี SKU ที่ unique

ฟิลด์สำคัญ
  • SKU — รหัสสินค้า (ต้องไม่ซ้ำกัน)
  • ชื่อสินค้า — ชื่อที่จะแสดงในใบ
  • หมวดหมู่ — พิมพ์ใหม่หรือเลือกจากที่มีอยู่แล้ว
  • ราคาทุน — ราคาที่ซื้อมา (Cost Price)
  • ราคาขาย — ราคาตั้ง (Selling Price)
  • Stock ปัจจุบัน — คำนวณจาก ซื้อเข้า - ขายออก อัตโนมัติ
💡 เกี่ยวกับ SKU

SKU คือ ID หลักของสินค้า สินค้าเดียวกันที่ขายใน Shopee, Lazada, TikTok ควรใช้ SKU เดียวกัน แล้วตั้ง Alias ไว้แทน

ดูสินค้าที่ Active/Inactive

ใช้ filter "Active" / "Inactive" เพื่อแสดงเฉพาะสินค้าที่ยังใช้งานอยู่ สินค้าที่ Inactive จะไม่ขึ้นใน dropdown ตอนสร้าง Invoice/PO

👥 ผู้จำหน่าย (Vendors)

จัดการข้อมูลซัพพลายเออร์ที่ซื้อสินค้ามาจาก

ฟิลด์สำคัญ
  • ชื่อบริษัท / ชื่อผู้ติดต่อ
  • เบอร์โทร / อีเมล
  • ที่อยู่
  • เลขภาษี (Tax ID) — ใช้ในเอกสารภาษี
  • บริษัท — ว่าผู้จำหน่ายนี้ supply ให้บริษัทไหน
ℹ️ หมายเหตุ

Vendor เดียวกันสามารถ supply ให้ได้หลายบริษัท ระบบจะ link ด้วย Company

💰 รายรับ / รายจ่าย (Transactions)

บันทึกรายรับ-รายจ่ายที่ไม่ใช่การซื้อ-ขายสินค้าโดยตรง เช่น ค่าเช่า, ค่าขนส่ง, ค่าซ่อม

ประเภทรายการ
💵 INCOME — รายรับ 💸 EXPENSE — รายจ่าย
หมวดหมู่ที่มี
🔧 ค่าซ่อม (Repair Service) 🚚 ค่าขนส่ง (Delivery) 👷 เงินเดือน (Salary) 🏠 ค่าเช่า (Rent) ⚡ ค่าสาธารณูปโภค (Utility) 📢 การตลาด (Marketing) 📌 อื่นๆ (Other)
💡 เคล็ดลับ

Transaction สามารถ link กับ Vendor ได้ เพื่อใช้สร้างใบ 50 ทวิ ทีหลัง

📥 นำเข้าข้อมูลจาก Platform (Shopee / Lazada / TikTok)

แทนที่จะพิมพ์ Order จาก Shopee/Lazada/TikTok เองทีละรายการ ระบบนี้ช่วย Import ไฟล์ Excel/CSV เข้ามาเป็น Invoice ให้อัตโนมัติ

วิธีใช้
1ไป Import Platforms ในเมนู
2เลือก Platform: Shopee / Lazada / TikTok
3อัปโหลดไฟล์ .csv หรือ .xlsx ที่ Export มาจาก Seller Center
4ระบบจะ ประมวลผลใน Background — ไม่ต้องรอหน้าจอ
5ดูสถานะการ Import ได้ที่ตาราง Import Log ด้านล่างหน้า
สถานะ Import Log
Pending — รอประมวลผล
Processing — กำลังนำเข้า...
Completed — สำเร็จทั้งหมด
Completed w/ Errors — สำเร็จบางส่วน
Failed — ล้มเหลว
⚠️ ถ้า Import แล้วมี Error

ให้ดาวน์โหลดไฟล์ Error Report เพื่อดูว่า Order ไหนมีปัญหา ส่วนใหญ่มักเกิดจากสินค้าที่ยังไม่ได้ Map SKU ไว้ในระบบ

ไฟล์ที่รองรับ
.csv .xlsx .xls
🔗 จับคู่สินค้า (Product Mapping)

เมื่อ Import จาก Platform มา สินค้าบางรายการอาจมีชื่อหรือ SKU ที่ระบบยังไม่รู้จัก หน้านี้ใช้ "บอก" ระบบว่าสินค้าตัวนั้นคือสินค้า SKU อะไรในระบบ

เมื่อไหรต้องมา Mapping?
  • Import แล้วสถานะเป็น Completed with Errors
  • มีรายการที่ขึ้นชื่อสินค้าเป็น "Unmapped" หรือว่างเปล่า
  • เพิ่งเพิ่มสินค้าใหม่เข้าระบบและยังไม่เคย Map
วิธีใช้
1ไปที่ Product Mapping ในเมนู
2จะเห็นรายการที่ยังไม่ได้ Map — มี Platform Name และชื่อสินค้าจาก Platform
3เลือก SKU ในระบบ ที่ตรงกัน แล้วกด Save
4ระบบจะ ย้อนหลังแก้ไข Invoice ที่ Import มาแล้วด้วย (Retroactive fix)
ℹ️ ทำครั้งเดียว ใช้ได้ตลอด

เมื่อ Map แล้ว ครั้งหน้า Import ไฟล์มาใหม่ ระบบจะจำ Mapping นี้ไว้ ไม่ต้อง Map ซ้ำอีก

📈 รายงาน (Reports)

ออกรายงานภาษีและ Stock เพื่อใช้ยื่นภาษีหรือตรวจสอบสินค้าคงเหลือ ดาวน์โหลดเป็น Excel ได้

ประเภทรายงาน
📋 รายงานภาษีซื้อ
ใบสั่งซื้อสถานะ Paid ทั้งหมดในช่วงเวลา
📋 รายงานภาษีขาย
ใบกำกับสถานะ Billed ทั้งหมดในช่วงเวลา
📦 รายงาน Stock
สินค้าคงเหลือทั้งหมด ณ ปัจจุบัน
📋 รายงานรวม
ภาษีซื้อ + ภาษีขาย ในไฟล์เดียว
วิธีออกรายงาน
1ไปที่ Reports ในเมนู
2เลือก ประเภทรายงาน
3เลือก บริษัท (หรือทุกบริษัท)
4เลือก ช่วงวันที่
5เลือก Basis: วันที่เอกสาร หรือ วันที่ออกภาษี
6กด Generate แล้วดาวน์โหลด Excel
💡 Basis คืออะไร?

วันที่เอกสาร = วันที่บนใบ PO / Invoice
วันที่ออกภาษี = วันที่ระบุในช่อง "วันที่ภาษี" ของ PO (ใช้เมื่อวันออกใบกับวันบนภาษีต่างกัน)

📋 VAT Tracking

ระบบติดตาม VAT แยกต่างหากจาก PO/Invoice หลัก ใช้ Import ข้อมูลจาก POS เพื่อตรวจสอบ VAT ซื้อและขาย

หน้า VAT Buy Summary

แสดงสรุปรายการซื้อทั้งหมด แยกตาม Document Number พร้อมยอดรวม สามารถดูรายละเอียดใน Order ได้

วิธี Import ข้อมูล VAT
1เตรียมไฟล์ Excel จาก POS ที่มีข้อมูลซื้อ/ขาย
2ไปหน้า VAT Tracking แล้ว Import
3ระบบจะแยก VAT / Non-VAT อัตโนมัติตามชื่อซัพพลายเออร์ (suffix /kit หรือ /s16)
4Export ออกเป็น Excel ได้ทุกเมื่อ
ℹ️ การแยก VAT อัตโนมัติ

ถ้าชื่อผู้จำหน่ายลงท้ายด้วย /kit หรือ /s16 ระบบจะจัดเป็น Non-VAT อัตโนมัติ

🏛️ ใบรับรองหักภาษี ณ ที่จ่าย (50 ทวิ)

ออกใบรับรองหักภาษี ณ ที่จ่าย (Withholding Tax Certificate) ตาม format ภาษีไทย พิมพ์ได้ 4 สำเนา

วิธีออกใบ 50 ทวิ
1ไปที่ 50 ทวิ ในเมนู
2เลือก แหล่งที่มา: ใบสั่งซื้อ (PO) / รายจ่าย (Transaction) / พิมพ์เอง
3ระบบดึงข้อมูล Vendor, จำนวนเงิน มาให้อัตโนมัติ
4เลือก ประเภทเงินได้ และ อัตราภาษี %
5กด Issue Certificate — ระบบออกเลขที่ใบรับรองให้อัตโนมัติ (รูปแบบ YYYY/0001)
6กด Print PDF เพื่อพิมพ์ 4 สำเนา
ประเภทเงินได้ที่รองรับ
เงินเดือน ค่าจ้าง/ค่าบริการ ค่าลิขสิทธิ์ ดอกเบี้ย เงินปันผล ค่าเช่า วิชาชีพ ค่าจ้างงาน (Contract) อื่นๆ
💡 เลขที่ใบรับรองอัตโนมัติ

ระบบออกเลขที่ต่อเนื่อง format 2568/0001, 2568/0002... แยกตามปี ไม่ต้องนับเอง

🏢 จัดการบริษัท (Companies)

ระบบรองรับหลายบริษัทในระบบเดียวกัน แต่ละบริษัทมีข้อมูลและเอกสารแยกกัน

ข้อมูลบริษัท
  • ชื่อบริษัท — ชื่อเต็ม ใช้ในเอกสาร
  • ชื่อย่อ (Nick Name) — ใช้แสดงใน dropdown
  • เลขภาษี (Tax ID) — 13 หลัก
  • ที่อยู่, เบอร์โทร, อีเมล
  • สถานะ Active/Inactive
⚠️ ข้อควรระวัง

การ Inactive บริษัทจะทำให้ไม่ขึ้นใน dropdown ตอนสร้างเอกสาร ตรวจสอบให้ดีก่อน

🔍 ค้นหาทั่วไป (Global Search)

Search box ที่ซ่อนอยู่ด้านบน (header) ใช้ค้นหาข้ามทุก Module พิมพ์แล้วกด Enter

ค้นหาได้จาก

🐛 แจ้งปัญหา / ขอฟีเจอร์ใหม่

เจอบัค หรืออยากได้ฟีเจอร์เพิ่ม แจ้งมาได้เลยผ่านหน้านี้ มี AI ช่วยตรวจสอบด้วย

วิธีแจ้งปัญหา
1ไปที่ Bug Reports ในเมนู

❓ คำถามที่พบบ่อย (FAQ)
ทำไม Stock สินค้าถึงไม่เพิ่มทั้งที่สร้าง PO แล้ว?
Stock จะเพิ่มก็ต่อเมื่อสถานะใบสั่งซื้อเป็น Paid เท่านั้น ถ้ายังเป็น Draft อยู่ Stock ยังไม่เข้า ลองเปลี่ยนสถานะเป็น Paid ดูครับ
Import จาก Shopee แล้วมี Error บางรายการ ต้องทำอะไร?
ดาวน์โหลด Error File จาก Import Log ก่อน จะเห็นว่า Order ไหนมีปัญหา ส่วนใหญ่ Error เกิดจากสินค้าที่ยัง Map SKU ไม่ได้ ให้ไปที่ Product Mapping แล้ว Map สินค้าให้ครบก่อน แล้วค่อย Import ใหม่ หรือถ้า Map แล้วรายการเก่าก็จะถูกแก้ไขย้อนหลังให้อัตโนมัติ
อยากออกรายงานภาษีซื้อ ต้องทำยังไง?
ไปที่เมนู Reports → เลือก "รายงานภาษีซื้อ" → เลือกบริษัทและช่วงวันที่ → กด Generate → ระบบจะออก Excel ให้ดาวน์โหลด ข้อมูลจะดึงจากใบสั่งซื้อที่สถานะ Paid ในช่วงวันที่ที่เลือก
ลบสินค้าออกจากใบกำกับที่ Billed แล้วได้ไหม?
ไม่ได้โดยตรง ถ้าต้องการแก้ไขใบที่ Billed แล้ว ต้องเปลี่ยนสถานะเป็น Cancelled ก่อน (Stock จะคืนกลับ) แล้วสร้างใบใหม่ หรือแก้ไขใบเดิมแล้วเปลี่ยนกลับเป็น Billed
FIFO คืออะไร ทำงานยังไง?
FIFO = First In, First Out หมายความว่า สินค้า Lot ที่ซื้อมาก่อนจะถูกขายออกก่อน เช่น ซื้อ iPhone มา 2 Lot: Lot A ราคาทุน 15,000 บาท, Lot B ราคาทุน 16,000 บาท เมื่อขาย ระบบจะดึงจาก Lot A ก่อน เพื่อให้ต้นทุนในการคำนวณกำไรถูกต้องที่สุด
เพิ่มบริษัทใหม่ต้องทำยังไง?
ไปที่เมนู Companies → กดปุ่ม "เพิ่มบริษัทใหม่" → กรอกข้อมูลชื่อบริษัท เลขภาษี ที่อยู่ → บันทึก หลังจากนั้นบริษัทใหม่จะขึ้นใน dropdown ตอนสร้าง PO/Invoice ได้เลย
เลขที่ใบ 50 ทวิ ระบบออกให้อัตโนมัติหรือต้องพิมพ์เอง?
ออกอัตโนมัติครับ รูปแบบ YYYY/ลำดับ เช่น 2568/0001, 2568/0002 เรียงต่อกันตามปี ไม่ต้องนับเอง
ดู Stock สินค้าได้จากที่ไหน?
ดูได้หลายที่: (1) หน้า Products มีคอลัมน์ Stock อยู่, (2) หน้า Dashboard มี Stock Alerts แสดงสินค้าใกล้หมด, (3) หน้า Reports → Stock Report จะออก Excel ทั้งหมด
ทำไมสินค้าบางตัวไม่ขึ้นใน dropdown ตอนสร้าง Invoice?
สินค้าที่ไม่ขึ้นใน dropdown อาจเป็นเพราะถูก set เป็น Inactive อยู่ ลองไปที่หน้า Products แล้ว filter ดู Inactive สินค้า ถ้าเจอให้เปิด Active กลับมา
Sync Google Sheet ใช้ทำอะไร?
ถ้ามีลูกค้าที่กรอก Google Form ขอใบกำกับภาษี ข้อมูลจะถูก Sync เข้ามาเป็น Invoice ในระบบให้อัตโนมัติผ่านปุ่ม Sync Google Sheet หน้า Invoice list ไม่ต้องพิมพ์ซ้ำ
🟢 สถานะต่างๆ ในระบบ
ใบสั่งซื้อ (Purchase Order)
Draft ร่าง ยังไม่ได้จ่ายเงิน Stock ยังไม่เข้า แก้ไขได้ทุกอย่าง
Paid จ่ายเงินแล้ว Stock เข้าระบบ แก้ไขรายการสินค้าไม่ได้ (แนบไฟล์ได้)
Cancelled ยกเลิกแล้ว Stock ไม่นับ
ใบกำกับ / ใบขาย (Invoice)
Draft ร่าง ยังไม่ตัด Stock แก้ไขได้ทุกอย่าง
Billed ขายแล้ว Stock ออกจากระบบ ใช้ในรายงานภาษีขาย
Cancelled ยกเลิก Stock คืนกลับ ไม่นับในรายงาน
ใบรับรอง 50 ทวิ
Draft ร่าง ยังไม่ออกเลขที่ใบรับรอง
Issued ออกใบรับรองแล้ว มีเลขที่ใบรับรอง พร้อมพิมพ์
